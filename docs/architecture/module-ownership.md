# Module ownership

Feature branches should use `feature/<module>`, `fix/<issue>`, or `refactor/<module>`. Backend feature work belongs inside `backend/src/modules/<module>`. Shared changes to `backend/src/app.js`, database configuration, package manifests, and global styling should be kept small and reviewed by the team.

Suggested ownership: auth/students/readiness; recruiters/jobs; matching; drives; offers/notifications; analytics; frontend UI/design system.
